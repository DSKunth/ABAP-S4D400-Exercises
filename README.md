# ABAP Programming S4D400 Exercises

Exercises from my learning journey **Acquiring Core ABAP Skills**, following the SAP course **S4D400 Basic ABAP Programming**. 

> **Work in progress.** This repository is updated as I complete the exercises of the S4D400 course. New classes are added over time.

## Exercises (package `ZS4D400_3964_EXERCISES`)

Each exercise is a global class that runs in the ADT console.

| Class | Topic |
|---|---|
| `ZCL_3964_HELLO_WORLD` | Ex. 3: Hello World application |
| `ZCL_3964_COMPUTE` | Ex. 4: A program that does calculations based on two numbers |
| `ZCL_3964_BRANCH` | Ex. 5: Implement conditional branching |
| `ZCL_3964_ITERATE` | Ex. 6: Work with simple internal tables (Fibonacci numbers) |
| `ZCL_3964_DEBUG` | Ex. 7: Debug ABAP code |
| `ZCL_3964_LOCAL_CLASS` | Ex. 8: Define a local class |
| `ZCL_3964_INSTANCES` | Ex. 9: Create and manage instances |
| `ZCL_3964_METHODS` | Ex. 10: Define and implement methods in local class then call these methods from the main( ) method of global class |

## How to run

Each class implements `IF_OO_ADT_CLASSRUN`. Open it in Eclipse with ABAP Development Tools (ADT), activate it with **Ctrl+F3**, and run it with **F9**. The output appears in the ABAP Console.

## Tools

ABAP Cloud, Eclipse with ADT, abapGit
